# Thiranex Capstone Submission Report

## Project
AbrarStore — E-commerce Product Catalog

## Requirements Demonstrated
1. **Modular frontend:** router, state/store, product data, reusable UI components and app entry point.
2. **Client-side routing:** `#/`, `#/products`, `#/products/:id`, `#/cart`, `#/favorites`.
3. **Performance:** lazy images, fixed image aspect ratios, minimal dependencies and Vite production bundling/minification.
4. **Production features:** search, filters, sorting, cart, wishlist, persistence, responsive design, theme switching and accessible controls.
5. **Deployment:** Vercel-ready `vercel.json` and standard Vite build.

## Stack
HTML5, CSS3, JavaScript ES Modules, Vite and localStorage.

## Learning Outcomes
SPA architecture, reusable components, routing, state management, responsive UI, accessibility, performance optimization and deployment workflow.
