# AbrarStore — Thiranex Capstone

Production-style e-commerce SPA demonstrating modular JavaScript, client-side routing, state management, responsive design, accessibility, performance optimization and deployment.

## Features
- Product catalog, search, category filter and sorting
- Product detail routes
- Cart with quantity controls
- Favorites / wishlist
- localStorage persistence
- Responsive mobile-first UI
- Light/dark theme
- Lazy-loaded images
- Loading/empty/error-friendly states
- Vite production build and minified assets
- Vercel-ready configuration

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Deploy
Import the GitHub repository into Vercel. Build command: `npm run build`; output: `dist`.

Suggested repository: `Thiranex-ecommerce-capstone`
